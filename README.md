# React Notes App

A simple notes management application built with React.

## Features

- Add Notes
- Delete Notes
- Dynamic List Rendering
- React useState Hook

## Technologies Used

- React JS
- JavaScript
- Bootstrap

## Concepts Used

- useState
- Event Handling
- Array Methods
- map()
- filter()

## Learning Outcome

This project demonstrates how to manage a list of notes using React state. Users can add new notes and delete existing notes dynamically.
